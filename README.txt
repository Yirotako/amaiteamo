# 💗 Carta para Amai

## Cómo abrirla

1. Abre `index.html` en Chrome, Edge o Safari.
2. Para probar la música, coloca un archivo MP3 dentro de `musica/`.
3. Abre `script.js` y revisa la sección `PERSONALIZA TU CARTA AQUÍ`.

## Música

Por derechos de autor, el proyecto no incluye la canción. Si tienes el archivo de audio que quieres usar, ponlo en:

`musica/la-mirada.mp3`

o cambia el nombre en `script.js`.

## Fotos

Reemplaza los espacios de foto por tus imágenes. Para la versión final podemos cambiar la estructura para que solo tengas que poner tus archivos en `fotos/`.

## Publicarla con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `style.css`, `script.js`, la carpeta `musica` y la carpeta `fotos`.
3. En el repositorio entra a Settings → Pages.
4. En "Build and deployment", selecciona "Deploy from a branch".
5. Selecciona la rama `main` y la carpeta `/root`.
6. Guarda y espera a que GitHub publique el sitio.

La dirección será parecida a:
`https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`

## Importante en iPhone

Los navegadores móviles suelen impedir que una página reproduzca audio automáticamente sin una interacción. Por eso el botón "Abrir mi carta" inicia la música mediante el toque de la persona.
